# 🎯 MediaPipe Project

A computer vision project utilizing MediaPipe for real-time pose/hand/face tracking and OpenCV for image and video processing.

## 📋 Prerequisites

Before you begin, ensure you have the following installed on your system:
- Python 3.11.9 (Highly recommended to avoid compatibility issues)
- pip (Python package installer)


## 📦 Installation


To ensure full compatibility with this project, please install the exact library versions listed below. 

1. **Install MediaPipe**:
```bash
pip install mediapipe==0.10.20
```

2. **Install OpenCV**
```bash
pip install opencv-python==4.11.0.86
```
